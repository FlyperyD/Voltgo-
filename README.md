# VOLTGO APK
1. Створіть порожній репозиторій на github.com і завантажте в нього всі файли цього архіву (включно з папкою .github).
2. Відкрийте вкладку Actions, дочекайтесь зеленої позначки (3–6 хв).
3. Відкрийте розділ Releases праворуч у репозиторії: там файл voltgo.apk. Натисніть на нього, щоб завантажити (на телефоні теж).
4. Перекиньте APK на телефон і встановіть (дозвольте встановлення з невідомих джерел).
Оновити застосунок: замініть www/index.html і зробіть commit.
