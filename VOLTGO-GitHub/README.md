# VOLTGO

Мобільний демоінтерфейс сервісу оренди павербанків. Проєкт розділений на HTML, CSS і JavaScript та підготовлений для GitHub Pages.

## Структура

```text
VOLTGO/
├── index.html
├── manifest.json
├── sw.js
├── icon.svg
├── css/
│   └── style.css
└── js/
    └── app.js
```

## Публікація через GitHub Pages

1. Створи новий репозиторій на GitHub, наприклад `voltgo`.
2. Завантаж у нього всі файли й папки з цього архіву (не сам ZIP).
3. Відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери **Deploy from a branch**.
5. Вибери гілку `main` і папку `/ (root)`, натисни **Save**.
6. Дочекайся публікації та відкрий адресу GitHub Pages, яку покаже GitHub.

## Як встановити на телефон

1. Відкрий опубліковане посилання на телефоні через Chrome (Android) або Safari (iPhone).
2. Android: меню браузера → **Install app** або **Add to Home screen**.
3. iPhone: кнопка **Поділитися** → **На початковий екран**.
4. Запускай VOLTGO з іконки на головному екрані.

PWA та Service Worker працюють через HTTPS — GitHub Pages це підтримує. Для повноцінної першої установки потрібне хоча б одне завантаження сторінки з інтернетом.

## Поточні обмеження демо

- Вхід через телефон / Google / Apple імітується локально.
- QR-сканування імітується кнопкою.
- Станції та кількість павербанків — демонстраційні дані.
- Оплата не підключена; дані картки не надсилаються платіжному провайдеру.
- Дані профілю та історії зберігаються у `localStorage` браузера на цьому пристрої.

Перед реальним запуском потрібні сервер/API, справжня авторизація, платіжний провайдер, керування станціями та юридично перевірені умови використання.
